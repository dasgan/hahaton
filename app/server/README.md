# Рабочая смена PicPac

Из папки `app` запустите `npm --prefix server start` и откройте
http://127.0.0.1:8787/admin/. Карточка заказа объединяет параметры печати,
переписку и статус. Кнопка «Заказы из приложения» показывает заказы,
хранящиеся в `server/data/`. Сообщения и статусы таких заказов сохраняет сервер.

Для самостоятельного просмотра откройте `admin/index.html` в браузере.
Примеры заказов и фотографии входят в комплект. Снимок с низким разрешением
помечен в очереди. Оператор может запросить исходник, подтвердить его получение
и передать заказ в печать. Для партии отпечатков 10×15 раскладка предполагает
четыре отпечатка на лист. Состояние примеров сохраняется в браузере, если он
разрешает локальное хранение.
