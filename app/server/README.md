# PicPac: демо диспетчерской смены

Из папки `app` запустите `npm --prefix server start` и откройте
`http://127.0.0.1:8787/admin/` на том же компьютере. Для показа не нужны
ключ админки, вход в аккаунт или настройка Wi-Fi. Демофотографии хранятся
в проекте, поэтому интерфейс не зависит от загрузки изображений из сети.

## Сценарий для питча

1. Нажмите **Показать новый заказ**. В очереди появится срочный постер, а
   счётчик проверки качества увеличится.
2. Откройте заказ и нажмите **Запросить исходник**. Админка подготовит
   сообщение клиенту. Отправка демонстрационного сообщения останется внутри
   браузера. Нажмите **Исходник получен**, чтобы показать переход к печати.
3. Нажмите **Сформировать партию**. Четыре совместимых заказа 10×15 на матовой
   бумаге перейдут в печать вместе. Раскладка и экономия листов — пример для
   презентации, а не производственный расчёт.
4. **Сбросить демо** возвращает начальный сценарий. Состояние демо сохраняется
   в браузере между перезагрузками страницы.

Кнопка **Заказы из приложения** появляется, когда локальный сервер получил
настоящие заказы. Она добавляет их к очереди; для таких заказов сообщения и
смена статуса записываются на сервер. Демозаказы на сервер не отправляются.

Данные заказов и загруженные фотографии находятся в `server/data/`. Это
локальный прототип: перед публичным запуском понадобятся авторизация и
защищённое соединение.
